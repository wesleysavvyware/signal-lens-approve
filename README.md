# Approve

The approval page for **Signal Lens** (core instance `srl`, Supabase project `fdpqirqnqdzexfudcrsx`). A static page:
it holds no secrets and does nothing until the owner signs in with his own Signal Lens password.

| File | What it is |
|---|---|
| `index.html` | The approval list ("Approve this job", "Add this change", "Put changes live"). Generated by `pcore changeset page --api https://fdpqirqnqdzexfudcrsx.supabase.co/functions/v1/owner-approve` (core 0.8.0). It talks only to Signal Lens's `owner-approve` function. |
| `reset.html` | Set your password, opened from the password recovery email. Uses only the public publishable key; the link's token leaves the address bar at once. |
| `mfa.html` | Set up your authenticator (6-digit code), so a stolen password alone can approve nothing. Public publishable key only. |

To regenerate `index.html` after a core upgrade, run the same `pcore changeset page` command with
`--out index.html` and commit it here. Allowed page origin for Signal Lens (`PCO_APPROVE_PAGE_ORIGINS`): the
address this site is served from, without the path (for GitHub Pages, `https://<account>.github.io`).
